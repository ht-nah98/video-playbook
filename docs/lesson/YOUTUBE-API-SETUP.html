Tạo client_secret cho YouTube API

Làm một lần, khoảng 10 phút. Xong rồi thì bản dịch title + mô tả 10 ngôn ngữ được gắn lên YouTube bằng một lệnh, không phải bấm tay trong Studio nữa. Miễn phí, không cần thẻ thanh toán.

Bạn sẽ tạo ra gì? Một "ứng dụng" riêng của bạn trên Google Cloud, chỉ bạn dùng. File client_secret.json là "chìa khoá" để công cụ của repo xin phép bạn sửa video. Công cụ chỉ thêm bản dịch, không đổi title, mô tả, tags hay thumbnail gốc.

Dùng đúng tài khoản Google. Đăng nhập bằng tài khoản Google bạn dùng để vào YouTube Studio của kênh 99% from scratch. Nếu bạn có nhiều tài khoản Google, kiểm tra ảnh đại diện góc trên bên phải trước mỗi bước.

1Tạo project

  1. Mở https://console.cloud.google.com. Lần đầu vào sẽ có hộp đồng ý điều khoản: chọn quốc gia, tick đồng ý, bấm Agree and continue.
  2. Bấm ô chọn project ở thanh trên cùng (cạnh logo Google Cloud, có thể ghi "Select a project") → New project.
  3. Project name: 99fs-tools (tên gì cũng được). Location: để "No organization". Bấm Create.
  4. Đợi vài giây, bấm vào chuông thông báo → Select project. Thanh trên cùng phải hiện 99fs-tools.

2Bật YouTube Data API v3 và YouTube Analytics API

  1. Ô tìm kiếm trên cùng, gõ YouTube Data API v3 → chọn kết quả có biểu tượng API (mục Marketplace / APIs).
  2. Bấm Enable. Trang chuyển sang "API/Service details" là xong.
  3. Làm lại y hệt với YouTube Analytics API (để Claude đọc số liệu kênh: nguồn lượt xem, giữ chân — chỉ đọc).

3Khai báo màn hình xin quyền (OAuth consent)

  1. Menu ☰ bên trái → APIs & Services → OAuth consent screen. Google có thể đưa bạn sang trang Google Auth Platform — đúng chỗ. Bấm Get started.
  2. App Information: App name 99fs translations; User support email: chọn email của bạn. Next
  3. Audience: chọn External. Next
  4. Contact Information: nhập email của bạn. Next
  5. Finish: tick đồng ý chính sách dữ liệu người dùng → Continue → Create.
Không cần điền logo, trang chủ, chính sách bảo mật, cũng không cần gửi Google xác minh — app chỉ để bạn tự dùng.

4Thêm chính bạn làm người dùng thử

  1. Trong Google Auth Platform, menu trái → Audience. Phần "Publishing status" để nguyên Testing.
  2. Kéo xuống Test users → + Add users → nhập email tài khoản Google bạn sẽ đăng nhập ở bước 7 (chính tài khoản đang dùng) → Save.
Không làm bước này thì lúc đăng nhập Google sẽ báo "Access blocked: … has not completed the Google verification process" (lỗi 403: access_denied).

5Tạo OAuth client và tải file JSON

  1. Menu trái → Clients → + Create client.
    (Giao diện cũ: APIs & Services → Credentials → + Create credentials → OAuth client ID.)
  2. Application type: chọn Desktop app. Name: mascot-mv. Bấm Create.
  3. Hộp "OAuth client created" hiện ra → bấm Download JSON. File tải về có tên dạng client_secret_123…apps.googleusercontent.com.json trong thư mục Downloads.
Tải ngay ở hộp này. Google hiện chỉ cho xem / tải client secret lúc vừa tạo. Lỡ đóng hộp mà chưa tải: mở client vừa tạo → Add secret để tạo secret mới rồi tải, hoặc xoá client và tạo lại.

6Cất file vào đúng chỗ

Trong Claude Code, gõ dòng dưới (dấu ! ở đầu để chạy lệnh ngay trong phiên):

! mkdir -p ~/.config/mascot-mv && mv ~/Downloads/client_secret_*.json ~/.config/mascot-mv/client_secret.json && chmod 600 ~/.config/mascot-mv/client_secret.json
File nằm ngoài repo nên không bao giờ bị commit. Đừng gửi file này cho ai, đừng dán nội dung vào chat.

7Báo Claude — đăng nhập lần đầu

  1. Nhắn Claude: "xong client_secret". Claude chạy: tools/i18n/.venv/bin/python tools/i18n/push.py --login Trình duyệt tự mở trang đăng nhập Google.
  2. Chọn tài khoản Google của bạn. Nếu Google hỏi chọn tài khoản hoặc kênh, chọn 99% from scratch.
  3. Màn hình "Google hasn't verified this app" là bình thường (app của chính bạn): bấm Advanced → Go to 99fs translations (unsafe).
  4. Màn hình xin quyền "Manage your YouTube account": tick ô quyền (nếu có) → Continue.
  5. Trình duyệt báo "The authentication flow has completed". Đóng tab. Trong terminal Claude sẽ thấy dòng Kênh: 99% from scratch (UC…).
Sau đó Claude làm tiếp: liệt kê video của kênh để khớp ID → chạy thử --dry-run cho video π và cho bạn xem → bạn đồng ý mới gửi thật cho 5 video → Claude đọc lại từ YouTube để soát title/mô tả gốc còn nguyên.

Lỗi hay gặp

Thấy gìLàm gì
"Access blocked … has not completed the Google verification process" Chưa thêm email vào Test users (bước 4), hoặc đăng nhập nhầm tài khoản khác.
Kênh: hiện tên khác, hoặc báo "không có kênh" Lúc đăng nhập đã chọn nhầm tài khoản / kênh. Nhắn Claude xoá token và đăng nhập lại, lần này chọn đúng 99% from scratch.
Lỗi 403 forbidden khi gửi bản dịch, dù đăng nhập đúng Studio của bạn ghi "You're a manager": nếu quyền này là quyền kênh trong Studio (Settings → Permissions) thì API không cho sửa video. Cách sửa: đăng nhập bằng tài khoản chủ sở hữu kênh, hoặc chủ kênh thêm bạn làm Manager của Brand Account (myaccount.google.com/brandaccounts). Claude sẽ báo nếu gặp.
Một tuần sau lệnh đòi đăng nhập lại Bình thường: app ở chế độ Testing, Google cho token sống 7 ngày. Trình duyệt tự mở, đăng nhập lại 30 giây là xong.
"quotaExceeded" Hạn mức miễn phí 10.000 điểm/ngày; mỗi video tốn ~50. Gần như không thể chạm; nếu có, đợi sang ngày (giờ Thái Bình Dương).

Sau này, mỗi video mới đăng

  1. Bạn nhắn Claude: "đăng rồi, làm bản dịch".
  2. Claude viết bản dịch 10 ngôn ngữ (tools/i18n/<bài>.py), thêm ID video, chạy thử, rồi gửi bằng một lệnh.
  3. Bạn mở Studio → Languages để nhìn lại (không phải gõ gì).
